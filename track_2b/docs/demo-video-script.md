# Demo video script (about 36 seconds)

1. **Title — 8 s:** Identify the project, scope and fictional-data boundary.
2. **Deterministic preflight — 10 s:** Show the allowlisted and excluded fields, plus `pending` and `no_send` states.
3. **Explicit live choice — 10 s:** Show that model inference requires an opt-in answer; the default makes no model request.
4. **Outcome — 8 s:** State that the output is a draft only and that no delivery capability exists.

The accompanying `Apertus_Draft_Gate_Demo.mp4` is an offline, captioned project overview. It deliberately does not portray a live model response that was not executed during local verification.
